# Ideation — paint-crawl

## Raw Ideas

- I want to use this myself, to build a database of paints for a paint mixing app
- The mixing app needs data about commercially available paints so users don't have to convert colors to hex values themselves
- Users should get accurate representations of real-world paints without manual entry
- paint-crawl is the data pipeline: crawl manufacturer sources, normalize paint data, produce importable presets

## Target Source

- http://www.art-paints.com/Paints/Art-Paints.html
- Crawl the site completely
- Coverage: all major painting mediums represented there (oils, acrylics, watercolors, etc.)

## Data to Capture

- Paint type (medium)
- Brand / manufacturer
- Color name
- Hex value

## Success in One Year

- A library of paints from the major manufacturers, kept up to date
- Accurate hex values
- All major painting mediums covered
- Output format the paint mixing app can consume as importable palette presets
